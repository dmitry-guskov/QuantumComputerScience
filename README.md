# QuantumComputerScience

## Overview
Welcome to the **QuantumComputerScience** repository! This repository serves as a collection of resources, tutorials, and solutions related to quantum computing and quantum machine learning (QML). It includes a variety of materials such as Qiskit examples, MOOC courses, quantum hackathon solutions, and tensor-related tutorials to aid researchers and enthusiasts in their quantum computing journey.

## Repository Structure

### 1. **Examples**
A collection of Qiskit examples demonstrating the implementation of basic Variational Autoencoders (VAE) in quantum computing.

### 2. **PracticalQCforScientists**
A forked course on practical quantum computing for scientists, providing fundamental and advanced topics on quantum algorithms and implementations.

### 3. **QHack2023-main**
A fork containing solutions to challenges from **QHack 2023**, a major quantum computing hackathon.

### 4. **QML/QML_Course**
A fork of the original GitLab repository for the **Quantum Machine Learning (QML) MOOC**, along with the official solutions. This course offers insights into the intersection of quantum computing and machine learning.

### 5. **TensorTutorials**
Official tutorials covering tensor libraries in Python, essential for understanding tensor-based quantum computing frameworks.
